Курсова робота на тему Проєктування АІС управління паркувальними місцями багатоповерхівки
Виконала Заїк Ірина 45 група
Метою роботи є проектування автоматизованої інформаційної системи управління паркувальними місцями багатоповерхового будинку, яка забезпечить зручний облік, розподіл та контроль використання паркомісць.
Для створення проєкту було використано мову програмування C# у середовищі Visual Studio.
